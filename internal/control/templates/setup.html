Don't know the address?

reostream can try every address on your network and see which ones answer on port 9000, the port these cameras speak. It opens one connection to every address in the range, so it is something you start, never something that happens on its own. It takes about half a minute.

{{/* Editable, not fixed, and never a dead end. The detected ranges come from this daemon's own interfaces, and in the shipped container those are docker's bridge network, 172.17.0.0/24 rather than the network the cameras are on. A container cannot know the operator's LAN, so the detected values are offered as suggestions and the operator has the last word. An earlier version rendered a fixed range with no way to change it, which on the deployment this project actually ships was a sweep of the wrong network with no recourse. */}}
{{range .Ranges}}

A private range, no larger than a /24. If reostream is running in a container, what it detects is the container's own network rather than yours: the address of a camera you already have is the quickest way to know what to type here.
